Leonida Trophy Guide — an offline, interactive tracker for all 55 GTA VI trophies, with rarity forecasts, a 3-stage platinum roadmap, and a spoiler-safe checklist.

## Run it

```sh
python3 -m http.server 8000 --directory app
```

Then open http://localhost:8000 in your browser.
